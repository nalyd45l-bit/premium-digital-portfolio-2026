# PREMIUM DIGITAL PORTFOLIO 2026

Новый персональный сайт Дмитрия Козлова в стиле White Liquid Glass. Старый репозиторий salary-increase-portfolio использован только как источник материалов и не изменялся.

Текущая версия содержит три раздела: fullscreen-знакомство, профессиональный путь на фоне второго видео и интерактивные навыки. Остальные разделы запланированы в TODO.md.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm run build
```

Vite создаёт статический каталог `dist/`. В среде, где домашний npm-кеш недоступен, передавайте `--cache /workspace/work/npm-cache` в `npm ci`.

## Архитектура

- `src/sections/` — Hero, Career, Skills.
- `src/components/` — VideoScene и GlassSculpture.
- `src/content/` — профиль, карьера, навыки и исходные описания четырёх проектов. Все данные редактируются здесь.
- `src/motion/` — GSAP и ScrollTrigger.
- `src/styles/` — шрифты, токены, стекло, адаптивные стили.
- `public/videos/` — два утверждённых неизменённых MP4.
- `public/images/` — извлечённые постеры.
- `public/source-materials/` — неизменённая копия прежних assets для будущих кейсов.
- `reference/` — PDF-резюме, исходный HTML, история QA и JSON-реестры. Не входит в public и не публикуется в dist.

Three.js импортируется при приближении к навыкам. Видео приостанавливаются вне экрана и в скрытой вкладке. Второе видео имеет preload="none". При reduced motion автоматическое воспроизведение и декоративные анимации отключены. Фоновое видео можно включить вручную.

## Публикация

Основной хостинг — Sites; его ID сохранён в `.openai/hosting.json`, статический каталог — `dist`. После `npm run build` публикуется собранный каталог, а не reference и не node_modules. Репозиторий GitHub создаётся отдельно от старого проекта и по умолчанию закрыт.

Для другого статического хостинга публикуйте dist с корневым base `/`. Для GitHub Pages в подпапке репозитория нужно предварительно согласовать и настроить Vite base, а также абсолютные пути к public-ресурсам. Текущую сборку нельзя без изменений обещать работающей в подпапке GitHub Pages.

Предложения работодателей и аналитика ещё не подключены. Нет фиктивной отправки форм, выдуманных просмотров или секретных ключей во frontend. Указанные результаты профессиональной работы — сведения автора; они не являются независимо проверенными измерениями.
