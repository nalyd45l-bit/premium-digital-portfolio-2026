Вкладка «Предложения», A:M: дата, компания, представитель, должность, предложение, валюта, формат, email, телефон, сообщение, статус, ID и согласие. Таблица без тестовых предложений. При создании проверены права: один owner, без anyone/domain/group.

Программный доступ к созданию и публикации Apps Script и управлению GA4 в текущем подключении отсутствует. Форма остаётся явно недоступной до подключения. Нельзя заменять подтверждение ответа `ok: true` на `mode: no-cors` и показывать фиктивный успех.

## Apps Script

1. В личной таблице: Расширения → Apps Script. Вставить `offers-apps-script.gs`.
2. В Script Properties задать:
   - `TARGET_SHEET_ID`: `1A6C9cAVfMTkG165PIDkD1jNpH9KOc7N3bKM2d0UiJU4`.
   - `TURNSTILE_SECRET`: секретный ключ Cloudflare Turnstile. Не публиковать в frontend.
   - `ALLOWED_HOSTNAME`: `premium-digital-portfolio-2026-dk.jocundblock16.chatgpt.site`.
   - `NOTIFY_EMAIL`: необязательно, личный адрес владельца для уведомлений.
3. Создать Turnstile widget для указанного hostname. Его публичный site key нужен frontend, secret остаётся только в Apps Script.
4. Опубликовать новую Web App, выполнение от имени владельца, доступ для посетителей. Таблицу не публиковать и не открывать по ссылке.
5. Передать URL `/exec` и публичный Turnstile site key. В локальной непрослеживаемой `.env.local` задать `VITE_OFFERS_ENDPOINT` и `VITE_TURNSTILE_SITE_KEY`, пересобрать сайт.
6. Проверить CORS/редирект ответа в настоящем браузере и реальную запись одной согласованной тестовой заявки. Если конфигурация Google блокирует CORS, нужен серверный relay; no-cors не использовать.
7. Вручную запустить `setupBackups` от имени владельца. Скрипт создаст закрытую папку резервных копий и ежедневный триггер. Копии старше 30 дней удаляются только из этой созданной папки и только с префиксом `Offers backup `. До запуска функции резервное копирование не считается активным.

Защита: обязательный CAPTCHA с проверкой hostname на сервере; honeypot; пределы размеров; проверка email, перечислений и согласия; минимальное время заполнения; блокировка параллельной записи; общий лимит 20 проверенных заявок в минуту; дедупликация ID; экранирование формул Google Sheets. GET не возвращает данные. В логах и аналитике нет полей предложения. Форма не хранится в localStorage.

## Google Analytics 4

Владелец создаёт GA4 Web Data Stream в своём Google-аккаунте и передаёт Measurement ID `G-...`. Затем задаётся `VITE_GA_MEASUREMENT_ID` в `.env.local` и пересобирается сайт. Это публичный идентификатор счётчика, не секретный ключ.

До настройки ID и согласия пользователя Google Analytics не загружается. Рекламные функции отключены; полные query string и referrer path не передаются. Не включать сбор пользовательских данных и Google Signals. В GA4 Enhanced Measurement отключить form interactions и site search, если они могут получать пользовательские значения.

События приложения: `section_view` (section_id), `project_open` (project_id), `contact_click` (фиксированный тип контакта), `resume_download` (нажатие на скачивание PDF), `offer_submit` (только после подтверждения записи). Нет имён, email, телефонов, зарплат, компаний или сообщений в параметрах событий. Переходы внутри сайта не включают данные формы в URL. Resume download — счётчик намерений скачать файл, не доказательство завершённой записи файла на устройство.

Страны, города и время взаимодействия — стандартные агрегированные данные GA4 в пределах доступности; абсолютная точность не гарантируется. Никакая публичная страница статистики не создаётся. Доступ к GA4 выдаёт только владелец в настройках Google Analytics.

Экспорт: GA4 → отчёт → Поделиться/Экспорт → CSV. Для Excel: импорт CSV в Excel с UTF-8 либо экспорт через Google Таблицы в XLSX. Предложения отдельно: приватная Google Таблица → Файл → Скачать → Microsoft Excel / CSV. Автоматический экспорт GA4 Data API без доступа к property не настроен.

## Оставшиеся зависимости

- Measurement ID GA4.
- Развёрнутый Apps Script `/exec`.
- Публичный Turnstile site key и серверный secret, настроенный владельцем.
- Запуск резервных копий и проверка реальной доставки/уведомлений.
